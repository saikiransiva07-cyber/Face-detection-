# Face Detection System

A computer vision web application built with Python, OpenCV, and Streamlit to detect faces from images and visualize detection results through a simple, interactive interface.

## 🚀 Live Demo

**Try the application here:**  
👉 https://cmoae4fnjysomyjwpvgmes.streamlit.app/

## ✨ Features

- Face detection using computer vision.
- Interactive web interface powered by Streamlit.
- Image processing using OpenCV.
- Simple and user-friendly workflow.
- Real-time visualization of detection results, depending on the selected input and application mode.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **OpenCV** – Image processing and computer vision.
- **Streamlit** – Interactive web application.
- **NumPy** – Numerical operations.
- **Pandas** – Data handling and analytics.
- **Pillow (PIL)** – Image processing.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/saikiransiva07-cyber/Face-detection-.git
```

### 2. Open the project folder

```bash
cd Face-detection-
```

### 3. Install the dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Start the application

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## 🎯 Project Objective

The objective of this project is to demonstrate how computer vision techniques can be integrated into a web application to identify faces in images and present the results through an accessible interface.
